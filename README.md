# Pinella

The scope of this project is to implement a fully working card game called `Pinella` from scratch using python and pygame. There will be two parts of the code: the server and the player. I'm writing this project to learn how to make a bigger project with less help from AI as possible. AI should never see or propose code, but I can use this tool as a tutor asking it questions regarding the general approach in order to learn something new

## Current Goals:
- make the game playable by a single player
- Implement the server and host a game with a friend
- have fun while learning something new

## Structure of the main files of the code:
- `game.py`: is the file that dispay the game to the user, should not know nothing about the rules of the game
- `engine.py`: is the one that knows the rules of the game
