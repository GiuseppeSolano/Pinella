# Pinella

The scope of this project is to implement a fully working card game called `Pinella` from scratch using python and pygames. There will be two parts of the code: the server and the player. I'm writig this project to learn how to make a bigger project with less help from AI as possbile. AI should never see or propose code, but I can use this tool as a tutor asking it questions regarding the general apporach in order to learn something new

## Current Goals:
- make the game playable by a single player
- Implement the server and host a game with a friend
- have fun while learning something new
